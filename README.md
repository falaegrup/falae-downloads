# Falaê — downloads

Site oficial: https://falae.pages.dev/

Este repositório está preparado para receber as versões oficiais dos aplicativos
Falaê para Android e computadores. Nenhum aplicativo novo foi publicado aqui.

Quando disponíveis, os instaladores estarão em **Releases**, acompanhados das
notas da versão e do arquivo SHA256SUMS. Os arquivos de código-fonte que o GitHub
gera automaticamente não são instaladores.

As assinaturas e os requisitos de instalação serão informados em cada versão.
